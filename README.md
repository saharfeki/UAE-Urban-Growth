# 🇦🇪 UAE Urban Growth & Land Cover Analysis

A collection of geospatial projects focused on **urban growth, land cover classification, and spatial analysis across the United Arab Emirates** using Sentinel-2 imagery, Google Earth Engine, OpenStreetMap, and machine learning.

## 📂 Projects

### 1. UAE Urban Growth Analysis (2018–2024)

A capstone project analyzing urban growth dynamics across the UAE using **Sentinel-2 imagery, Google Earth Engine, and Random Forest classification**.

**Main topics:**
- Land cover classification
- Urban growth analysis
- Spectral indices
- Change detection
- GIS visualization

[📁 View Project →](./UAE-Urban-Growth-2018-2024 _1.0/)

---

### 2. Automated Land Cover Classification

An automated workflow for classifying land cover across the UAE using **Sentinel-2, Google Earth Engine, OpenStreetMap labels, and Random Forest**.

**Main workflow:**

`Data Preparation → Label Extraction → Feature Extraction → Random Forest → Prediction → Post-Processing`

**Classes:**
- 🏙️ Urban
- 🌱 Vegetation
- 🏜️ Desert / Bare Soil
- 💧 Water

**Analysis periods:**
- 2018
- 2021
- 2024

[📁 View Project →](./UAE-Urban-Growth-2018-2024 _2.0/)
