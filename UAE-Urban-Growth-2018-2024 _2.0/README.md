# 🇦🇪 UAE Urban Growth Analysis (2018–2024)

This repository contains my capstone project on urban growth dynamics in the United Arab Emirates using Sentinel-2 imagery and Google Earth Engine.

## Project Description
- Land cover classification using Random Forest
- Classes: Urban, Vegetation, Bare Soil, Water
- Spectral indices: NDVI, NDBI, MNDWI, BUI, DUI
- Period: 2018–2024
- Platform: Google Earth Engine

##  Repository Structure
- `Code/` : Google Earth Engine JavaScript code
- `Report/` : Final report (PDF)
- `Presentation/` : Defense presentation
- `Figures/` : Maps and figures

## Tools & Technologies
- Google Earth Engine
- Sentinel-2
- Random Forest
